# UI test assets

## P1.5b pinned font

- `fonts/LiberationSans-Regular.ttf` — Liberation Sans 2.1.5, OFL-1.1.
- `fonts/LiberationSans-OFL.txt` — upstream license/copyright text.
- `fonts.json` — family/path/SHA-256/version/license/source manifest.
- `metrics.json` — deterministic oracle generated by
  `scripts/ui-font-metrics.py` directly from the font tables (no fontTools).

The font is a **test asset only**. `ui`, `ui_fonts`, and applications do not link
or embed it by default. Regenerate and check the oracle with:

```bash
python3 scripts/ui-font-metrics.py
python3 scripts/ui-font-metrics.py --check
```
