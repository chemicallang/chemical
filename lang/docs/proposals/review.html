Second pass — 2026-10-13 (full log: DECISIONS.md)

  • 06 Native GC — approved. Per-module gc = true; GC modules may only depend on GC modules (a GC module in a non-GC build errors); conservative Boehm-style collector; borrow checking kept, @delete optional.
  • 08 Web/DOM types — approved. First-party dom module shipped with the compiler (generated once from Web IDL, versioned).
  • 05 Effects — approved. Square brackets; v1 effects panic, pure, blocking, unsafe, alloc, noreturn; restrictions are per-function (plus a module default); effects are declared, never inferred across current-module forward calls; unreachable/traps are unsafe, not panic.
