# Phase 2 public API audit

Generated by `scripts/safety-sharpen-api-audit.sh`; snapshots live in
`api/<lib>.txt`, unsafe-boundary maps in `unsafe/<lib>.md`, and the reviewed
legacy allowlist is `API_ALLOWLIST.md`.

The audit separates four things:

- `RAW_PUBLIC`: every public function whose signature mentions a raw pointer.
- `RAW_NONRAW`: those declared **outside** a `raw`/`ffi`/`sys` namespace. This
  is the safe-surface gate: safe-by-default means this number is zero or a
  reviewed entry in `API_ALLOWLIST.md`.
- `UNSAFE_PUBLIC`: public `unsafe func`/`unsafe struct` declarations (normal use
  must go through a safe wrapper).
- `SAFE_NAMED`: public functions whose name still carries a `safe_`/`_safe`
  qualifier. It must be zero: safe is the default name (see `AGENTS.md`).

The snapshot script fails closed if `rg` is missing instead of silently writing
empty snapshots.

## Result

The 2026-11-09 API-freeze wave made the safe names canonical, and the
2026-11-12 safe-by-default wave removed the parallel `*_safe` / `safe_*` /
`::safe::` spellings and moved the remaining raw codec/accessor entry points
into `image::raw` / `audio::raw` / `font::raw` (see `BREAKING.md`). New user
code uses `std::io`, safe `fs` helpers, `PathBuf`, `process::Child`,
`net::TcpListener`/`TcpStream`, `tls::TlsStream`/`TlsServerStream`,
`page.escape_*`/`page.append_*`, the `encoding`/`crypto`/`compression`/
`archive`/`image`/`audio`/`font` safe facades, the safe `regex`/`json`/`mime`/
`cbor` forms, `window::Window`/`webview::WebView`, and
`compiler::api`/`lab::*`.

`RAW_NONRAW` is zero for 21 of 29 libraries (`fs`, `path`, `encoding`, `crypto`,
`compression`, `archive`, `image`, `audio`, `font`, `regex`, `json`, `mime`,
`cbor`, `router`, ...). The remaining nonzero entries are the reviewed
allowlist in `API_ALLOWLIST.md`; `image`, `audio`, and `font` no longer appear
there at all.

`compiler`/`lab` (Tier B) are tracked separately: `compiler::api` keeps a small
raw hand-off (`IndexOperator::get_idx`, `ASTBuilder::allocate_size`), and
`lab`'s raw build hooks live under `lab::raw`.
