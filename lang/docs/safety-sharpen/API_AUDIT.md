# Phase 2 public API audit

Generated by `scripts/safety-sharpen-api-audit.sh`; snapshots live in
`api/<lib>.txt`, unsafe-boundary maps in `unsafe/<lib>.md`, and the reviewed
legacy allowlist is `API_ALLOWLIST.md`.

The audit separates ordinary public raw-pointer APIs from explicit public
unsafe declarations. Tier C (`cstd`, compiler CBI raw bindings, platform FFI) is
out of scope.

## Result

The safe surface is additive. Legacy raw-buffer entry points remain for in-tree
callers and are recorded as reviewed migration debt in `API_ALLOWLIST.md`; new
user code uses `std::io`, safe `fs` helpers, `PathBuf`, `process::Child`,
`net::TcpListener`/`TcpStream`, `tls::TlsStream`/`TlsServerStream`,
`safe_page_*`, the `encoding`/`crypto`/`compression`/`archive`/`image`/`audio`/
`font` safe facades, the safe `regex`/`json`/`mime`/`cbor` forms, and
`compiler::api`/`lab::safe`. A new ordinary public raw-pointer API requires an
allowlist entry and an invariant.
